# Renders e Imagenes Promocionales — Valle Alto

Imagenes de alta calidad para usar como thumbnails, pantalla splash o
material de marketing dentro del recorrido.

## Archivos esperados

| Archivo                     | Uso                                           |
|-----------------------------|-----------------------------------------------|
| render-sala.jpg             | Thumbnail de la escena sala en el sidebar     |
| render-cocina.jpg           | Thumbnail escena cocina                       |
| render-alcoba-principal.jpg | Thumbnail escena alcoba principal             |
| render-fachada.jpg          | Hero image para el splash screen              |

## Especificaciones

- Resolucion minima: 800x600 px para thumbnails
- Formato: JPG quality 80-90 (balance tamano/calidad)
- No necesitan ser equirectangulares — son imagenes normales

## Nota

Los thumbnails son opcionales. Si no se proveen, el sistema omite la miniatura
en el sidebar y muestra solo el nombre de la escena.
